# MAiTRI 2025 - International Conference on AI, ML & Deep Learning  

## 🌐 Project Overview  
MAiTRI 2025 is an **international conference** dedicated to advancements in **Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL)**. This webpage serves as an **informative and submission portal**, providing essential details about the conference, including venue, dates, submission guidelines, and more.

---

## 🚀 Features  
✅ **Conference Information** – Displays conference name, date, and venue.  
✅ **Attractive Design** – Dark blue and yellow theme for high contrast and readability.  
✅ **Domain Selection** – Dropdown menu for selecting a research domain (AI, ML, DL).  
✅ **Paper Submission Button** – Directs users to submit their papers.  
✅ **Important Dates Section** – Highlights key deadlines.  
✅ **QR Code Integration** – Provides a scan-to-access feature for additional details.  
✅ **Responsive Layout** – Ensures compatibility across all devices.
